# 폐기물 이미지 분류 모델 개발 프로젝트 보고서
### Garbage Classification via Transfer Learning (ResNet18)

본 프로젝트는 ImageNet 사전학습 ResNet18을 기반으로 쓰레기 이미지 6종을 분류하는 모델을 개발한 딥러닝 입문 프로젝트입니다. 기준점(모델 최초성능) 수립, 데이터 불균형 보완, 파인튜닝, 테스트셋 최종 측정, 모델 저장에 이르는 전 과정을 단계별로 수행하였으며, 모든 실험은 변수를 하나씩 통제하고 동일한 진단 도구로 비교하는 원칙을 유지하였습니다.

**최종 성능 (테스트셋 380장, 1회 측정): accuracy 0.88 / macro f1 0.88 / trash f1 0.86**
(최초성능 대비 accuracy 0.79 → 0.88, 최소수 클래스 trash f1 0.55 → 0.86)

---

## 1. 프로젝트 개요

- **과제**: TrashNet 기반 쓰레기 이미지 6종 분류 (cardboard, glass, metal, paper, plastic, trash)
- **기반 모델**: ImageNet 사전학습 ResNet18 전이학습
- **데이터**: Garbage imgs x 2,527, train/val/test = 70/15/15 층화 분할 (1,768 / 379 / 380)
- **클래스 불균형**: paper 594장 ~ trash 137장으로 최대·최소 클래스 간 약 4.3배 차이 존재
- **개발 환경**: Google Colab (T4 GPU), PyTorch
- **공통 조건**: input 224×224, ImageNet 기준 데이터 정규화, batch size 32, Adam(lr=0.001)
- 실험 1~6의 성적은 검증셋 기준이며, 테스트셋은 모든 튜닝이 종료된 후 최종 측정에 1회만 사용하였습니다.

## 2. 기록

### 실험 1. 기준성능(최초성능) - 전이학습, fc층만 학습 (10에폭)
조건: conv1~layer4 전체 freeze, fc층(512→6)만 학습. 증강 및 손실 가중치 없음.

| 클래스 | precision | recall | f1 |
|---|---|---|---|
| cardboard | 1.00 | 0.85 | 0.92 |
| glass | 0.76 | 0.76 | 0.76 |
| metal | 0.70 | 0.82 | 0.76 |
| paper | 0.82 | 0.94 | 0.88 |
| plastic | 0.72 | 0.67 | 0.69 |
| trash | 0.75 | 0.43 | 0.55 |

accuracy 0.79 | macro f1 0.76

trash recall이 0.43에 그쳤다. 소수 클래스(학습셋 96장)가 다수 클래스에 밀려 소극적으로만 예측되는 문제가 확인되었으며, 이후 실험의 개선 목표로 설정하였다.

### 실험 2. 데이터 증강 (15에폭)
조건: RandomHorizontalFlip(0.5) + RandomRotation(15°) + ColorJitter(밝기·대비 ±0.2). 학습셋에만 적용.

| 클래스 | precision | recall | f1 |
|---|---|---|---|
| cardboard | 0.98 | 0.74 | 0.84 |
| glass | 0.81 | 0.59 | 0.68 |
| metal | 0.57 | 0.92 | 0.70 |
| paper | 0.84 | 0.78 | 0.81 |
| plastic | 0.65 | 0.75 | 0.70 |
| trash | 0.67 | 0.48 | 0.56 |

accuracy 0.73 | macro f1 0.71

trash 개선은 미미했고(recall 0.43→0.48) 전체 성능은 하락하였다(0.79→0.73). 이는 증강 기법 자체의 결함이라기보다, trash 클래스의 문제가 각도·색상의 다양성 부족이 아닌 원본 데이터의 종류와 절대량 부족에 있어 기하·색상 변형으로는 해결되지 않기 때문으로 해석된다. 본 기법은 기각하였다.

### 실험 3. 손실 가중치 - 클래스 장수 역수 (10에폭)
조건: CrossEntropyLoss(weight = 전체 장수 / (6 × 클래스 장수)). trash 가중치 약 3.1.

| 클래스 | precision | recall | f1 |
|---|---|---|---|
| cardboard | 0.95 | 0.87 | 0.91 |
| glass | 0.79 | 0.71 | 0.75 |
| metal | 0.71 | 0.74 | 0.73 |
| paper | 0.89 | 0.82 | 0.85 |
| plastic | 0.67 | 0.75 | 0.71 |
| trash | 0.47 | 0.67 | 0.55 |

accuracy 0.77 | macro f1 0.75

trash recall은 0.43→0.67로 상승했으나 precision이 0.75→0.47로 하락하였다. trash에 부여된 가중치가 지나치게 높아 다른 클래스의 표본까지 trash로 예측하는 경향이 나타난 것으로, 손실 가중치는 정답이 trash인 표본의 손실만 확대하므로 "놓침"은 강하게 벌하되 "오분류 유입"은 벌하지 않는 비대칭이 recall 상승과 precision 하락의 원인이다. trash f1은 0.55로 변화가 없었다.

### 실험 4. 손실 가중치 완화 - 제곱근 적용 (10에폭)
조건: 실험 3의 가중치에 제곱근을 적용하여 강도를 완화. trash 가중치 약 1.75.

| 클래스 | precision | recall | f1 |
|---|---|---|---|
| cardboard | 0.90 | 0.92 | 0.91 |
| glass | 0.84 | 0.71 | 0.77 |
| metal | 0.75 | 0.92 | 0.82 |
| paper | 0.87 | 0.84 | 0.86 |
| plastic | 0.69 | 0.71 | 0.70 |
| trash | 0.58 | 0.52 | 0.55 |

accuracy 0.80 | macro f1 0.77

가중치 강도에 비례하여 trash 지표가 실험 3(0.47/0.67)과 기준점(0.75/0.43) 사이의 중간 지점(0.58/0.52)으로 이동하였다. f1은 여전히 0.55에 머물렀다. **실험 1~4를 통해, fc층만 학습하는 구조에서는 가중치 조절이 recall과 precision의 배분만 변경할 뿐 종합 성능(f1)을 향상시키지 못함을 확인하였다.**

### 실험 5. 파인튜닝 - layer4 및 fc층 학습 (10에폭)
조건: layer4의 freeze를 해제하고 층별 학습률을 차등 적용(layer4=0.0001, fc=0.001). 손실 가중치 없음.

| 클래스 | precision | recall | f1 |
|---|---|---|---|
| cardboard | 1.00 | 0.95 | 0.97 |
| glass | 0.89 | 0.87 | 0.88 |
| metal | 0.80 | 0.87 | 0.83 |
| paper | 0.94 | 0.94 | 0.94 |
| plastic | 0.84 | 0.88 | 0.86 |
| trash | 0.83 | 0.71 | 0.77 |

accuracy 0.89 | macro f1 0.88

전 지표가 큰 폭으로 상승하였다(accuracy 0.80→0.89, macro f1 0.77→0.88). 특히 trash는 손실 가중치 없이도 precision(0.75→0.83)과 recall(0.43→0.71)이 동시에 상승하여, 실험 1~4에서 관찰된 두 지표 간 상충 관계가 사라졌다. 이는 trash 클래스 부진의 근본 원인이 데이터 부족만이 아니라 모델의 특징 구별 능력 부족에 있었음을 보여준다.

한편 학습 손실이 4에폭 만에 0.02대로 급락하고 검증 손실은 3에폭(0.3056)에서 최저점을 기록한 후 반등하여, 표현력 증가에 따른 과적합이 이른 시점에 시작됨을 확인하였다.

### 실험 6. 파인튜닝 + 제곱근 완화 가중치 — 최종 채택 모델
조건: 실험 5의 구성에 제곱근 완화 손실 가중치를 추가.

**6-1. 에폭 10 실행 (과적합 시작점 확인)**: 검증 손실이 6에폭(0.3317)에서 최저점을 기록한 후 반등(10에폭 0.3924)함을 확인하고, 이를 근거로 학습 에폭을 5로 재설정하였다(수동 조기 종료).

## 3. 최종 성능 측정 - 테스트셋

모든 설계 및 튜닝이 종료된 후, 어떠한 의사결정에도 사용되지 않은 테스트셋(380장)으로 최종성능을 1회 측정하였다.

| 클래스 | precision | recall | f1 | support |
|---|---|---|---|---|
| cardboard | 0.92 | 0.92 | 0.92 | 60 |
| glass | 0.92 | 0.79 | 0.85 | 76 |
| metal | 0.80 | 0.92 | 0.86 | 62 |
| paper | 0.90 | 0.91 | 0.91 | 89 |
| plastic | 0.86 | 0.90 | 0.88 | 73 |
| trash | 0.94 | 0.80 | 0.86 | 20 |

**accuracy 0.88 | macro f1 0.88**

검증 대비 변화(최종 모델): accuracy 0.91→0.88, macro f1 0.89→0.88, trash f1 0.81→0.86

- 테스트 정확도가 검증 대비 소폭 낮게(-0.03) 측정되었다. 에폭 수, 가중치 강도, freeze 범위 등 모든 설계를 검증 셋 성적을 근거로 결정하였으므로, 누수되지 않은 데이터셋으로 테스트 측정 결과 성능이 소폭 낮게 측정되었다. 다만 격차가 작아 튜닝이 검증셋에 과도하게 적합되지는 않았다고 판단된다.
- trash f1이 테스트에서 더 높게 측정된 것(0.81→0.86)은 모델 개선이 아닌 표본 크기 효과로 해석된다. trash는 검증 21장, 테스트 20장에 불과하여 표본 1~2장의 차이로 지표가 크게 변동하므로, trash 성능은 "f1 약 0.8 내외"로 이해하는 것이 타당하다.
- glass가 최약 클래스로 확인되었다(recall 0.79, glass→metal 7장·glass→plastic 8장 오분류). 재질 유사성에 의한 혼동은 검증과 테스트 모두에서 일관되게 나타나는 본 데이터의 구조적 한계로 판단된다.

## 5. 분석

**실험 1 ~ 4** fc층만 학습한 단계이다. trash f1이 0.55~0.56에 고정된 채 precision과 recall의 배분만 이동하였다(0.75/0.43 → 0.47/0.67 → 0.58/0.52). 모델의 구별 능력 총량이 고정된 상태에서, 사용처만 바뀌는 상황으로 해석된다.

**실험 5 ~ 6.** layer4의 freeze를 해제하여 특징 추출기 자체를 대상 데이터에 맞게 조정하였다. 능력 총량이 확장되면서 trash의 precision과 recall이 상충 없이 동시에 상승하였고 전 클래스의 성능이 개선되었다. 다만 표현력 증가로 인해 과적합이 3~6에폭에서 시작되어, 에폭 축소(조기 종료)로 대응하였다.

**검증→테스트.** 최종 일반화 성능은 accuracy 0.88이다. 검증 대비 -0.03의 격차는 검증셋 기반 튜닝에 내재된 낙관의 보정으로 해석되며, 격차가 작아 모델 선택 과정은 건전하였다고 판단된다.

**한계.**
- 실험 5(10에폭)와 실험 6(5에폭)은 가중치 유무와 에폭 수의 두 변수가 동시에 달라, 최종 개선분의 원인(가중치 효과 대 조기 종료 효과)이 분리되지 않는다.
- trash 표본이 20~21장으로 적어 trash 지표는 ±0.05 이상의 변동 폭을 가진다.
- glass↔metal↔plastic 간 상호 혼동은 재질 유사성에서 기인하는 구조적 한계이다.

## 6. 결론 및 향후 과제

- **채택 모델**: ResNet18 파인튜닝(layer4+fc 해제, 층별 학습률 0.0001/0.001) + 제곱근 완화 손실 가중치, 5에폭 학습
- **최종 성능 (테스트셋)**: accuracy 0.88, macro f1 0.88, trash f1 0.86
- **핵심 인사이트**: 소수 클래스 문제의 해법이 학습 규칙의 조정(가중치)이 아닌 모델 표현력의 확장(파인튜닝)에 있었다. 학습 규칙만 변경한 네 차례의 실험이 모두 trash f1 0.55에 정체된 반면, 특징 추출기를 데이터에 맞게 조정하자 두 지표의 상충 없이 0.77~0.86까지 상승하였다.
- **향후 과제**: trash 원본 데이터 확충(증강이 아닌 수집), glass 계열 혼동 완화를 위한 추가 파인튜닝(layer3 해제 실험), 조기 종료 자동화(early stopping 구현)
